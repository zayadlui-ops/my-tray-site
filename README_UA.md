# My Tray — офіційний сайт (v3)

Статичний сайт для GitHub Pages, без бекенду.

## Файли
- `index.html` — структура сайту, розділи, перемикач мов.
- `style.css` — оформлення та CSS-анімація орбіт.
- `app.js` — каталог, пошук, модальні деталі модулів, UA/EN.
- `catalog.json` — спільний структурований каталог, задуманий для майбутнього читання сайтом і програмою.
- `MODULE_FORMAT.md` — опис полів каталогу.
- `UPDATE_GUIDE_UA.md` — інструкція з оновлення для початківця.

## Мови
Перемикач EN/UA розташований у правому верхньому куті. Мова вибору зберігається у браузері. Для англомовних карток модулів підтримуються необов'язкові поля `name_en`, `short_description_en`, `description_en`.

## Анімація
Orbit tracks реалізовані CSS-анімацією з різними швидкостями. Наведення зупиняє відповідну орбіту. У налаштуваннях системи `prefers-reduced-motion` анімація мінімізується.

## Публікація
Заміни файли у репозиторії GitHub Pages. Не видаляй файл `CNAME`, якщо він існує. Докладна інструкція: `UPDATE_GUIDE_UA.md`.

## Важливо
Каталог і пряме завантаження з My Tray — архітектурний задум/наступний етап, а не вже реалізована функція. На цьому етапі сайт читає `catalog.json`.
