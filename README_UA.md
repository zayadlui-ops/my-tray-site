# My Tray — офіційний сайт (версія 2)

Це статичний сайт My Tray, розміщений на GitHub Pages та підключений до домену `360.pp.ua`. Дизайн зберігає темну технологічну стилістику й зелений акцент, але використовує адаптивне компонування hero-секції, щоб графічне ядро не перекривало текст.

## Файли
- `index.html` — структура сторінки.
- `style.css` — стилі та адаптивне компонування.
- `app.js` — відображення каталогу, пошук, фільтри, картки й діалог деталей.
- `catalog.json` — каталог та інформація про реліз My Tray.
- `MODULE_FORMAT.md` — чернетка формату метаданих модулів і задум інтеграції із застосунком.

## Публікація оновлення на GitHub Pages
1. Відкрий репозиторій сайту на GitHub.
2. Завантаж файли з архіву, замінивши старі `index.html`, `style.css`, `app.js`, `catalog.json` та README.
3. Додай `MODULE_FORMAT.md`.
4. Commit changes.
5. Дочекайся завершення GitHub Pages Actions (якщо налаштований workflow) або автоматичного оновлення Pages.
6. Відкрий `https://360.pp.ua` і онови сторінку. Якщо браузер показує стару версію — зроби hard refresh або очисти кеш.

Не змінюй DNS-записи, якщо сайт уже працює.

## Як додати модуль у каталог
Відредагуй `catalog.json`, додавши запис до масиву `modules`. Поля описані в `MODULE_FORMAT.md`. Пакет модуля має бути розміщений на HTTPS-сумісному джерелі, наприклад у GitHub Releases. У записі вкажи пряме посилання на файл, версію, опис, сумісність, автора й контрольну суму SHA-256, якщо вона доступна. Commit змін у `catalog.json` — після оновлення сторінка прочитає новий каталог.

## Підготовка інтеграції із My Tray
Цей сайт не є інсталятором. Він відображає каталог і дає посилання на пакети. Для програми My Tray пропонується в майбутньому використовувати той самий JSON-каталог як API-подібне джерело даних:
- URL каталогу: `https://360.pp.ua/catalog.json`
- парсинг JSON, перевірка версії формату та полів;
- кешування й резервування останнього коректного каталогу;
- завантаження пакетів з HTTPS;
- перевірка SHA-256 та сумісності перед встановленням;
- підтвердження користувачем, встановлення, оновлення та видалення модулів.

**Важливо:** SHA-256 підтверджує відповідність файлу заявленому хешу, але не доводить авторство. У перспективі доцільно додати підпис каталогів/пакетів і механізм довірених видавців. My Tray не має автоматично виконувати неперевірені пакети.

## GitHub Pages та домен
Якщо сайт уже опублікований і домен `360.pp.ua` працює, не потрібно повторно налаштовувати домен або DNS. Публікація нових файлів відбувається через репозиторій.
