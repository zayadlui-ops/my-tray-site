# My Tray — офіційний сайт (v7)

Статичний сайт для GitHub Pages, без бекенду.

## Файли
- `index.html`, `style.css`, `app.js` — сайт (UA/EN).
- `catalog.json` — єдине джерело даних: програма, категорії, модулі. Той самий файл читатиме застосунок My Tray.
- `media/` — відео модулів. `favicon.svg`, `robots.txt`, `sitemap.xml`.
- `MODULE_FORMAT.md` — поля каталогу. `UPDATE_GUIDE_UA.md` — інструкція публікації та оновлення.

## Ідея «сонячної системи»
У центрі My Tray, модулі з `catalog.json` обертаються навколо нього літерами назви (MW, NM, CM, MD, TB). Кожен модуль має власну орбіту, швидкість і напрямок. Клік веде на сторінку модуля (`#module-<id>`) з описом і відео. Новий модуль у каталозі з’являється на орбіті автоматично, код змінювати не потрібно.

## Модулі
З сайту модулі не завантажуються: тільки програма My Tray (з сайту завантажується лише вона). Сторінка модуля пояснює це й веде до завантаження програми.

## Анімація
Наведення зупиняє орбіту. Кнопка під малюнком ставить усю анімацію на паузу. Якщо в Windows вимкнені ефекти анімації (prefers-reduced-motion), сайт стартує на паузі, кнопка запускає її вручну.
