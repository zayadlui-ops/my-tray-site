# Екосистема My Tray: як усе повʼязано

```
Адмін-панель (сайт/admin)  --коміт-->  GitHub: catalog.json  --Pages-->  360.pp.ua (сайт читає той самий файл)
        |                                    |
        | SHA-256 + посилання                +--raw.githubusercontent.com--> застосунок My Tray (резервне джерело)
        v                                                                 |
GitHub Releases: .zip модулів і файл програми  <--завантаження + перевірка SHA-256-- застосунок My Tray
```
- **Єдине джерело правди — `catalog.json`.** Сайт показує його, застосунок читає його, адмінка його редагує.
- **Файли** (програма, пакети модулів) лежать у GitHub Releases, а не в репозиторії. Сайт їх не віддає: модулі ставляться лише з My Tray.
- **Застосунок** бере каталог із `https://360.pp.ua/catalog.json`; якщо домен недоступний, з `raw.githubusercontent.com`; якщо немає мережі, з локального кешу.

## 1. Одноразове налаштування
1. Опублікуйте сайт (`UPDATE_GUIDE_UA.md`), перевірте, що `https://<домен>/admin/` відкривається.
2. Створіть токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate. Repository access: *Only select repositories* → репозиторій сайту. Permissions → Repository permissions → **Contents: Read and write** (більше нічого). Термін 30–90 днів.
3. Відкрийте `/admin/`, вкажіть власника, репозиторій, токен → «Завантажити з GitHub».

## 2. Додати або оновити модуль
1. Зберіть пакет: **zip**, у корені якого лежить `.exe` модуля (його шлях вкажете в полі «Запускний .exe»). Назва файлу без пробілів, наприклад `motion-wallpaper-1.0.0.zip`.
2. GitHub → Releases → Draft a new release → тег `motion-wallpaper-v1.0.0` → завантажте zip → Publish.
3. Адмінка → «+ Новий» (або виберіть існуючий) → заповніть поля → у блоці «Пакет модуля» виберіть той самий zip: SHA-256, розмір і посилання підставляться самі → статус `available`.
4. «Зберегти в GitHub». Через 1–10 хв модуль зʼявиться на орбіті сайту й у каталозі застосунку.
Правила: версія змінюється лише вгору (1.0.0 → 1.0.1); файл релізу не підмінюють (потрібен новий реліз і новий хеш); застарілий модуль не видаляють, а переводять у `archived`.

## 3. Оновити програму
Реліз із тегом `v1.2.0` → у розділі «Програма» адмінки виберіть файл, введіть версію й дату → Зберегти. Застосунок побачить версію, більшу за свою, і запропонує оновлення.

## 4. Відкат
Помилковий модуль: змініть статус на `hidden` і збережіть (застосунок перестане його пропонувати). Зіпсований каталог: GitHub → файл `catalog.json` → History → попередня версія → Revert. Сайт не зламається від некоректного каталогу: перед збереженням адмінка перевіряє його, а GitHub Action `Validate catalog` повідомить про помилку після коміту.

## 5. Рекомендації (за пріоритетом)
1. **Підписування.** SHA-256 захищає від пошкодження й підміни файлу, але якщо зловмисник отримає доступ до вашого акаунта, він змінить і файл, і хеш. Наступний крок безпеки: підпис пакетів (Authenticode для `.exe` або підпис каталогу ключем Ed25519, який перевіряє застосунок). Без підпису Windows SmartScreen попереджатиме про нові `.exe`.
2. **Акаунт GitHub:** двофакторна автентифікація, токен лише з Contents на один репозиторій, короткий термін, не зберігати в нотатках і чатах. Токен, що витік, одразу відкликайте (Settings → Tokens → Revoke).
3. **Дані користувача модулів** (відео Motion Wallpaper, історія буфера, статистика мережі) зберігайте в `%AppData%\MyTray\<id>\`, а не в папці модуля. Оновлення не видаляє сторонніх файлів у папці модуля, але видалення модуля стирає всю папку.
4. **Оновлення запущеного модуля** неможливе (файли зайняті): застосунок має закрити модуль, оновити й запустити знову.
5. **Версіонування каталогу:** `catalog_version` змінюйте лише при несумісних змінах; застосунок має ігнорувати невідомі поля й за більшої версії показати «оновіть My Tray».
6. **Тестування перед випуском:** чиста Windows 10 і 11 (віртуальна машина), без мережі, при розбіжності хеша, запущений модуль під час оновлення, антивірус (при хибних спрацюваннях на нові `.exe` надсилайте збірки на аналіз розробникам антивірусів і в Microsoft).
7. **Приватність:** запит каталогу бачить хостинг (IP). Не додавайте телеметрію без згоди й опишіть це на сайті.
8. **Залежності:** GitHub Pages і Releases безкоштовні з лімітами (трафік ≈ 100 ГБ/міс для Pages), домен `360.pp.ua` залежить від реєстратора: тому застосунок має резервний URL на raw.githubusercontent.com.
9. **Резервні копії:** раз на місяць «Download ZIP» репозиторію й копія релізних файлів на власний диск.

## Що перевірено, а що ні
Перевірено в браузері на макеті GitHub API: завантаження каталогу, додавання модуля, перевірка полів, SHA-256, збереження, конфлікт версій. **Не перевірено:** робота з реальним GitHub (токен, CORS, ліміти), C# код не компілювався (у моєму середовищі немає .NET SDK) і не вбудований у ваш застосунок, адмінка не тестувалась у Safari/Firefox.
