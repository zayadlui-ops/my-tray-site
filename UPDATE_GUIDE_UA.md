# My Tray Website v5 — інструкція оновлення

## Замінити на GitHub лише ці 4 файли
- index.html
- style.css
- app.js
- catalog.json

1. Відкрий репозиторій My Tray на GitHub.
2. Add file → Upload files.
3. Вибери чотири файли з цієї папки (не завантажуй вкладену папку цілком).
4. Якщо GitHub показує конфлікт/підтвердження заміни, підтверди.
5. Commit changes.
6. Зачекай 3–5 хвилин.
7. Відкрий сайт у приватній вкладці або зроби примусове оновлення сторінки.

**Не видаляй CNAME**, якщо він є в репозиторії. DNS та Pages налаштування не змінюй.

## Перевірка
- У шапці натисни EN: текст має перейти англійською, кнопка стане UA.
- Натисни UA: текст повернеться українською.
- Піктограми в графіці праворуч мають обертатися навколо центрального My Tray.
- Наведи курсор на піктограму, щоб призупинити її орбіту.

Якщо кнопка або анімація не працює, надішли скриншот GitHub-репозиторію з переліком файлів і скриншот сайту. Не повторюй завантаження навмання.
