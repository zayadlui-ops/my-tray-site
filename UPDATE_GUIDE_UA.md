# My Tray website update v3 — інструкція для початківця

## Що нового
- Збережено попередній дизайн і колірну гаму.
- Орбітальні модулі рухаються навколо My Tray Core; орбіти мають різні швидкості.
- Наведення на планету підсвічує її та зупиняє орбіту.
- Додано перемикач українська / English у верхній правій частині.
- Анімація спрощується для системних налаштувань Reduced Motion.
- Сайт та каталог залишаються статичними; JSON-каталог збережено як основу для інтеграції з програмою.

## Як оновити сайт на GitHub (з телефона або ПК)
1. Відкрий GitHub і зайди у свій репозиторій сайту.
2. Відкрий папку/список файлів репозиторію. Не переходь до Settings і не змінюй налаштування домену.
3. Завантаж ZIP `MyTray_Official_Website_v3.zip` та розпакуй його на пристрої.
4. У розпакованій папці `mytray_site` знайди файли `index.html`, `style.css`, `app.js`, `catalog.json`.
5. У репозиторії GitHub відкрий кожен файл із такими самими назвами. Для заміни відкрий файл, натисни значок олівця **Edit**, виділи старий вміст і заміни його новим вмістом відповідного файлу з архіву. Збережи зміни кнопкою **Commit changes**. (Якщо GitHub у твоєму інтерфейсі дозволяє завантажити файли через **Add file → Upload files**, простіше завантажити всі чотири файли з кореня папки `mytray_site`, але не завантажуй саму папку як вкладену папку.)
6. Повтори заміну для кожного з чотирьох файлів. Не видаляй `CNAME`, якщо він присутній у корені репозиторію: він може містити прив'язку домену.
7. Після завантаження/commit почекай кілька хвилин. Відкрий сайт `https://360.pp.ua` і зроби оновлення сторінки. На телефоні, якщо зміни не видно, спробуй відкрити сайт у приватній вкладці або очистити кеш браузера.
8. Натисни **EN** у правому верхньому куті, щоб перевірити англійську, та **UA** для повернення.

## Якщо GitHub заплутує
Не змінюй DNS, Pages, домен, Actions або Settings. Якщо не бачиш кнопок чи не впевнений, надішли скриншот — підкажу точний наступний крок.

## Що не завершено
- Не підключені реальні завантаження програми та модулів.
- Каталог наразі демонстраційно порожній.
- Англійський текст на картках модулів буде показаний із полів `name_en`, `short_description_en`, `description_en`, якщо вони додані в JSON; без них використовується український текст.
- Орбітальні символи — поки демонстраційні, не пов'язані з фактичними модулями каталогу.
