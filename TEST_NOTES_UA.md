# Технічні примітки v5

- CSS анімація орбіт переписана окремими keyframes із центрованим positioning.
- Перемикач мови прив'язується окремим listener; зміна мови не залежить від завантаження JSON.
- localStorage обгорнуто в try/catch, щоб блокування storage не ламало перемикач.
- URL CSS/JS змінені на v5 для оновлення кешу.
- Це перевірка статичних файлів і синтаксису; реальний браузер/ваш GitHub deployment не був доступний для live-тесту.
