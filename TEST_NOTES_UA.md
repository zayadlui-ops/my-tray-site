# Нотатки перевірки v7

Перевірено у headless Chromium (локальний сервер): орбіти рухаються (різні напрямки й швидкості), пауза та відновлення, клік відкриває сторінку модуля, повернення до каталогу, EN/UA, помилка для невідомого модуля, відсутність горизонтального прокручування при 375 px, відсутність помилок JavaScript.
Не перевірено: Safari/Firefox, реальні телефони, GitHub Pages, домен, відео (файлів ще немає).

## Знайдені проблеми v6 і виправлення
- Причина нерухомої анімації: у `@keyframes` було `!important`, браузери ігнорують такі декларації, тож анімація не мала жодних кадрів. Крім того, у CSS накопичилося кілька конфліктних шарів правил орбіт (v3–v6): їх замінено одним блоком.
- Повідомлення про помилку каталогу миттєво перезаписувалося текстом-заглушкою.
- Кнопка «Файл ще не опубліковано» мала `href="#"` і стрибала нагору.
- Закриття діалогу спрацьовувало при кліку по його внутрішніх відступах (діалог замінено сторінкою модуля).
- Не було `og:type`, canonical, іконки, `robots.txt`, `sitemap.xml`; частина aria-підписів була англійською.
- Відомо: шрифт Manrope підвантажується з Google Fonts (зовнішній запит). Для повної відсутності сторонніх запитів завантажте шрифт у репозиторій і підключіть локально.
